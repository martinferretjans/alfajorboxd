# Alfajorboxd

Aplicación web para registrar y calificar alfajores.

## Requisitos

- Go instalado (1.25 o superior)

## Cómo ejecutar

```bash
git clone -b tp1 https://github.com/martinferretjans/alfajorboxd.git
cd alfajorboxd
go run main.go
```

El servidor queda escuchando en http://localhost:8080/
