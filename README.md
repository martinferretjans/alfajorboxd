# Alfajorboxd

Aplicación web para registrar y calificar alfajores.

## Requisitos

- Go instalado (1.25 o superior)

## Cómo ejecutar

```bash
# Por SSH 
git clone git@github.com:martinferretjans/alfajorboxd.git

# Por HTTPS
git clone https://github.com/martinferretjans/alfajorboxd.git

cd alfajorboxd
go run main.go
```

El servidor queda escuchando en http://localhost:8080/
